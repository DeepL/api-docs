### API Limits

| Type of limit      | Maximum limit                                   |
| ------------------ | ----------------------------------------------- |
| Header size        | 16 KiB (16\*1024 bytes)                         |
| Total request size | 128 KiB (128\*1024 bytes)                       |

### Maximum Upload Limits Per Document Format

The maximum file size depends on the format and your plan. The per-document character limit is shown below the table:

| File Format                     | DeepL API - free plans         | DeepL API - paid plans           |
| --------------------------------| ------------------------------ | -------------------------------- |
| Word (.docx / .doc)             | 10 MB  | 100 MB |
| PowerPoint (.pptx)              | 10 MB  | 100 MB |
| Excel (.xlsx)                   | 10 MB  | 30 MB  |
| Excel Macro-Enabled (.xlsm)\*\* | 10 MB  | 30 MB  |
| PDF (.pdf)                      | 10 MB  | 100 MB |
| Text (.txt)                     | 1 MB   | 1 MB   |
| HTML (.html)                    | 5 MB   | 5 MB   |
| IDML (.idml)                    | 10 MB  | 30 MB  |
| MIF (.mif)                      | 10 MB  | 30 MB  |
| XML (.xml)                      | 10 MB  | 10 MB  |
| JSON (.json)                    | 1 MB   | 1 MB   |
| YAML (.yaml / .yml)\*\*         | 1 MB   | 1 MB   |
| Java Properties (.properties)\*\*| 1 MB  | 1 MB   |
| iOS/macOS Strings (.strings)\*\*| 1 MB   | 1 MB   |
| Markdown (.md / .markdown)\*\*  | 1 MB   | 1 MB   |
| DITA (.dita)                    | 5 MB   | 5 MB   |
| XLIFF (.xlf/.xliff)\*           | 10 MB  | 10 MB  |
| SRT (.srt)                      | 150 KB | 150 KB |
| WebVTT (.vtt)\*\*               | 150 KB | 150 KB |
| SCORM (.zip)\*\*                | 10 MB  | 10 MB  |
| RESX (.resx)\*\*                | 1 MB   | 1 MB   |
| ODT (.odt)\*\*                  | 10 MB  | 30 MB  |
| RTF (.rtf)\*\*                  | 10 MB  | 30 MB  |
| Images (.jpeg/.png)\*\*         | 3 MB   | 3 MB   |

*DeepL supports XLIFF versions 1.2, 2.0, and 2.1 (2.1 shares the 2.0 core namespace).<br />
**Currently in Beta. During the Beta phase, characters translated in these file formats are not billed and not counted against your character threshold.

Separately from file size, a single document submitted via the API can contain up to 500,000 characters on free plans and up to 5 million characters on paid plans (previously 1 million). The limit applies to the document as a whole, not to each format or part.

<Note>
These limits apply to documents submitted through the DeepL API. Uploads through the DeepL web app and desktop apps use separate limits.
</Note>

### Your Usage

Retrieve usage information within the current billing period together with the corresponding account limits.

Usage is returned and tracked for translated characters. Note that for [text translation](/api-reference/translate/request-translation), characters are still counted toward billing when the source and target languages are equal.

Character usage includes both text and document translations, and is measured by the source text length in Unicode code points. For example, "A", "Δ", "あ", and "深" are each counted as a single character. The `character_count` field returned by the [`/usage` endpoint](/api-reference/usage-and-quota/check-usage-and-limits) is a sum of Translate API and Write API characters.
