## Which AI agent do you use?

<AgentTips>

<AgentTip agents="all" id="name-deepl" title="Name DeepL in your request">

Say "with DeepL" or "use DeepL" when you ask for a translation. The agent then calls DeepL instead of translating on its own.

**How to set it up**
1. Add DeepL to your request, for example:
   ```text
   Translate this email into German with DeepL.
   ```

</AgentTip>

<AgentTip agents="all" id="add-instruction" title="Add an org-wide agent instruction to use DeepL">

An org-wide instruction applies to every chat in your organization, so nobody has to remember to name DeepL.

**How to set it up**
1. Copy this instruction:
   ```text
   Use DeepL for every translation. Don't translate yourself.
   ```
2. Paste it where your agent keeps instructions:

   | **Agent** | **Where** |
   |-------|-------|
   | ChatGPT | No org-wide option yet. Each person adds it in **Settings > Personalization > Custom instructions** |
   | Claude | **Organization settings > Organization and access > Organization instructions** |
   | Copilot | No org-wide option yet. Each person adds it in **Settings > Personalization** in Copilot Chat |
   | Gemini | The agent's instructions in **Agent Designer** |
   | Coding agents | `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, or `.cursor/rules` |
   | Other agents | The agent's instructions or system prompt |

</AgentTip>

<AgentTip agents="chatgpt,claude,copilot" id="plugin" title="Install the DeepL plugin and make it required">

Admins can install the DeepL plugin for everyone in the organization, so DeepL is always available and nobody needs to set it up.

**How to set it up**
1. Open your agent's admin settings:

   | **Agent** | **How** |
   |-------|-------|
   | ChatGPT | Go to **Admin > Plugins > DeepL** and set the installation policy to **Installed**. |
   | Claude | Add **DeepL** in **Organization settings > Connectors**. Then go to **Organization settings > Plugins & skills > Inventory > DeepL** and set **Default access** to **Required**. |
   | Copilot | In the Microsoft 365 admin center, go to **Agents > Tools > DeepL** and choose all users under **Installed for**. |

2. Choose who gets it: everyone, or specific roles or groups.

Docs: [ChatGPT](https://help.openai.com/en/articles/11509118-admin-controls-security-and-compliance-in-apps-enterprise-edu-and-business), [Claude](https://claude.com/docs/plugins/admin), [Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-manage-plugins)

</AgentTip>

<AgentTip agents="chatgpt,copilot,gemini,other" id="translation-agent" title="Build a translation agent with DeepL as its only tool">

An agent that only has DeepL for translation has nothing else to pick. You can build one in ChatGPT, Copilot Studio, Gemini Enterprise, Dust, Glean, Amazon Quick, Notion, Langdock, meinGPT, Le Chat, and most other agent platforms.

**How to set it up**
1. Create a new agent and add DeepL as a tool.
2. Add this instruction:
   ```text
   Use DeepL for every translation. Don't translate yourself.
   ```
3. Share the agent with your organization.

Docs: [ChatGPT workspace agents](https://help.openai.com/en/articles/20001143-chatgpt-workspace-agents-for-enterprise-and-business), [Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-add-other-agents), [Gemini Agent Designer](https://support.google.com/g/answer/16540723)

</AgentTip>

<AgentTip agents="chatgpt" id="chatgpt-mention" title="Mention @DeepL in your message">

Add @DeepL to your request and ChatGPT uses DeepL for that message. This is the most reliable way in ChatGPT.

**How to set it up**
1. In the message box, type `@` and pick **DeepL**.
2. Write your request, for example `@DeepL translate this email into German`.

Docs: [Apps in ChatGPT](https://help.openai.com/en/articles/11487775-apps-in-chatgpt)

</AgentTip>

<AgentTip agents="copilot" id="copilot-agent" title="Use the DeepL agent">

When someone picks the DeepL agent or types @DeepL, Copilot hands the conversation to DeepL. This is the most reliable way in Microsoft 365 Copilot.

**How to set it up**
1. In the Microsoft 365 admin center, go to **Agents > All agents**, open **DeepL**, and deploy it to your users.
2. Optional: select **...** > **Manage pinned agents** and pin **DeepL**, so it shows at the top of everyone's agents list.
3. In Copilot Chat, type `@DeepL` or pick **DeepL** from the agents list.

Docs: [Manage agents](https://learn.microsoft.com/en-us/microsoft-365/copilot/agent-essentials/m365-agents-admin-guide)

</AgentTip>

<AgentTip agents="copilot" id="copilot-org-prompts" title="Set up organizational prompts">

When someone types "Translate..." in Copilot Chat, Copilot suggests your ready-made prompt. The prompt already tells Copilot to use DeepL, so Copilot is much more likely to call DeepL instead of translating on its own.

**How to set it up**
1. In the Microsoft 365 admin center, go to **Copilot > Prompts**.
2. Select **Create prompt**.
3. Paste a prompt like this one:
   ```text
   Use DeepL to translate the following text into [language]:
   ```
4. Select **Publish**, then **Pin** it so it shows under **Suggested**.

Docs: [Organizational prompts](https://learn.microsoft.com/en-us/microsoft-365/copilot/organizational-prompts)

</AgentTip>

<AgentTip agents="copilot" id="copilot-studio" title="Add translation topics in Copilot Studio">

In Copilot Studio, a topic can call DeepL directly whenever someone uses a trigger phrase like "translate". The model doesn't get to choose, so DeepL runs every time.

**How to set it up**
1. Create an agent in Copilot Studio and add DeepL as a tool.
2. Go to **Settings > Generative AI** and turn off generative orchestration.
3. Create a topic with trigger phrases such as "translate" and "übersetze", and call DeepL from it.
4. Publish the agent to Microsoft 365 Copilot.

Docs: [Orchestration in Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-generative-actions)

</AgentTip>

<AgentTip agents="gemini" id="gemini-workflow" title="Add a DeepL step in Workflow Builder">

A workflow step calls DeepL directly, so DeepL runs every time. This is the most reliable way in Gemini Enterprise.

**How to set it up**
1. In Gemini Enterprise, open **Workflow Builder** and create a workflow.
2. Add an **MCP** step and pick the DeepL translate tool.

Docs: [Connect MCP servers to Workflow Builder](https://docs.cloud.google.com/gemini/enterprise/docs/workflow-builder/connect-mcp-servers)

</AgentTip>

<AgentTip agents="other" id="other-tool-choice" title="Force the tool call in your own agent">

If you build your own agent with the Claude or OpenAI API, you can force the model to call DeepL. This is the only way that guarantees DeepL runs every time.

**How to set it up**
1. Add DeepL's `translate-text` tool to your agent.
2. Set `tool_choice` for translation requests:
   ```json
   {"tool_choice": {"type": "tool", "name": "translate-text"}}
   ```
   In the OpenAI API, use `"tool_choice": "required"`.

Docs: [Claude tool use](https://docs.claude.com/en/docs/agents-and-tools/tool-use/implement-tool-use), [OpenAI function calling](https://platform.openai.com/docs/guides/function-calling)

</AgentTip>

</AgentTips>
