---
openapi: delete /v3/example_documents/{example_document_id}
title: "Delete an example document"
description: "Permanently delete an example document so that translations can no longer reference it."
---

There is no recovery step, and the content of an example document cannot be exported before deletion.

To replace an outdated example document, see [Adapting translations with example documents](/docs/customize/using-example-documents#remove-an-example-document).
